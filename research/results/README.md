# 長期回測結果（規則 v1.2，2020/1/2–2026/11/16）

檢驗方法在看到資料前寫在 `research/backtest.py` 檔頭，門檻沒有調整。價格已用官方除權息與減資參考價調整。
報酬：訊號隔天開盤買、第5個交易日收盤賣，扣 1.1%；開盤一價漲停視為買不到。

## 結論
1. **是波動雷達，不是方向雷達。** 活躍度排名預測「5日漲 ≥ 15%」的 AUC 0.74，預測「5日跌 ≤ −15%」0.75，七年都差不多。
2. **精選沒有比「仍在動的其他股票」好。** 每一年精選的5日報酬中位數都比較低，賠10%以上的比例也比較高。
3. **不重疊每週比較也看不出優勢**：331週，精選減仍在動其他平均 +0.34 個百分點，中位數 −0.10，t = 1.12，95% 區間 −0.21 到 +0.94。
4. **原因之一是隔夜跳空**：精選股隔天平均開高 1.04%，開盤才買就吃不到；若能在訊號當天收盤買，精選平均 −0.09%、仍在動其他 −0.22%，差距仍很小，且漲停股收盤通常買不到。

## drops.py — 大跌時的扛跌與反彈（2026/11/18 事先登錄）
大跌事件：等權指數比近20日高點低 ≥ 6%（2020 年以來 21 次）。
A（事先登錄）：觸發日能算的 7 個條件（扛跌、大跌前強、法人買超、投信買超、大股本、高波動、仍在動），隔天開盤買、10日超額報酬，
  沒有一個在 2020–2023 與 2024–2026 都穩定（方向相同、差 ≥ 2 個百分點、2/3 事件一致）。仍在動兩段約 +0.9 / +1.1 個百分點，不夠。
B（事後描述）：以真正的低點來看，高點到低點跌最深的一成，低點後10日平均多漲 3.7 個百分點（20 次中 15 次勝過跌最少的一成）。低點只有事後才知道。
探索性（看過 A、B 後才做）：前段最扛跌的一成，之後20日在大盤下跌日合計 −10.8%（跌最多的一成 −16.6%），大盤上漲日 +13.0%（+20.5%）；
  19/20 次扛跌延續、20/20 次反彈落後。扛跌與反彈快是同一件事（股票動得大或小）的兩面。
這次（10/28→11/06 −16.1%、→11/13 +8.5%、→11/17 −7.9%）：兩段下跌的個股報酬相關 0.73；反彈與第二段下跌相關 −0.47。
網站：大跌事件進行中時，大盤卡片可直接看「高點以來」最抗跌／跌最多。
