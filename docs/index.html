  • 七年每一年，精選的報酬中位數都低於「仍在動的其他股票」，賠10%以上的比例也比較高。
  • 活躍度預測大漲和大跌的能力一樣（AUC 0.74 對 0.75），七年都是如此：這是波動雷達。
  • 精選股隔天平均開高1.04%，等開盤才買就把可能的優勢吃掉了。
  • 不重疊每週比較（331週）：精選比仍在動其他平均多0.34個百分點，但中位數−0.10、統計上不顯著。

結論：目前的價量條件找得到會大幅波動的股票，但沒有證明能挑出會漲的。名單請當觀察用，不要當買進訊號。

覆核後最重要的修正：這是「波動雷達」

三份外部覆核都指出同一個問題，我用資料驗證後確認：同一個活躍度指標，預測大跌的能力和預測大漲幾乎一樣強。

所以：清單當作值得盯的高波動股，不是買進訊號。門檻先不再調，改用「追蹤」頁的實際結果和事先定好的停止條件來判斷。

精選的門檻怎麼定的

四個條件全部符合才入選：

  • 活躍度前10%：波動、振幅、平均真實波幅、漲停天數、近期最大5日漲幅的綜合排名（上市、上櫃分開排）。
  • 今天或前10個交易日內有漲停（單日漲9%以上，近似值），排除早就熄火的。
  • 當天上漲：收盤高於前一天收盤（不是紅K棒）。
  • 量能比至少2：近5日平均成交額是近20日的2倍以上，代表資金正在湧入。

前三個條件之前已驗證過；量能比的門檻這次用每日資料重新定。做法是先只看7/28到9/30（訓練期）挑門檻，再拿10/1到11/6（驗證期）檢查。報酬是隔天開盤買、第5個交易日收盤賣，扣約1.1%成本。

量能比≥2把檔數從每天約20多檔減到約6檔，兩段期間的平均報酬都比較好。量能比在1到2之間的放在「觀察」。

我也試過加上波動、振幅、距高點、20日漲幅等門檻：在訓練期看起來最好的組合，到驗證期反而變差，所以沒有採用。也試過用「大盤站上20日均線的比例」決定要不要選股，兩段期間結果相反，同樣沒有採用。

風險：精選股在大盤下跌時一樣會跌，而且賠10%以上的比例明顯比全體高（驗證期30%對18%）。驗證期只有約5週，請看「追蹤」頁累積的實際結果。

要看清楚的地方

  • 這個規則找出的是大漲機率高約2.5到3倍的股票，但它們跌起來也更兇。10月到11/2大盤走弱，入選股的平均報酬比全體更差，單週跌20%以上的比例是漲20%以上的三倍。
  • 方向主要看大盤。11/2當週個股報酬中位數約−12%，11/9當週約+6.5%。入選股只是把大盤的漲跌放大。
  • 「量能增溫」（近5日均額不低於近20日）標籤，在三個期間都比單看活躍度略好，但差距小，樣本也少，只當參考。
  • 只有15週、一段行情。我沒有找到其他穩定有效的特徵。我先前憑感覺設的「突破20日高點、放量2倍」，資料不支持：大漲股反而多半離高點較遠。

名單之後表現如何

每天收盤後，「仍在動」的完整名單（含精選、觀察）都會存檔，之後不再修改。報酬算法：隔天開盤買、第5個交易日收盤賣，扣約1.1%成本。開盤一價漲停視為買不到、不計入；出場日跌停鎖死順延；持有中停牌用最後收盤。

比較三組：精選、仍在動的其他股票（同樣高波動，最公平的對照）、全體。精選要贏過「仍在動的其他股票」，加上去的條件才算有用。

「實際」是 起的名單，才算真正的驗證；「回測」是規則制定期間的名單，只供參考。

事先定好的停止條件

在看到實際結果之前先寫下，避免邊看邊改：累積約26週（130個交易日）實際結果後，如果精選的5日報酬中位數不高於「仍在動的其他股票」，或精選賠10%以上的比例超過35%，就停用精選分級，只保留「仍在動」當觀察名單。在那之前不調整門檻。

資料與更新

行情來自證交所與櫃買中心每日收盤資料，雲端排程每個平日台北18:30自動抓取並重新計算。清單包含近20日平均成交額1,000萬元以上、已有60日行情的上市櫃普通股。

各欄位

  • 精選：活躍度前10%、今天或前10個交易日內有漲停、當天上漲、量能比至少2。
  • 觀察：同上，但量能比在1到2之間。
  • 新進：今天進入精選、昨天還不在。
  • 處置：證交所或櫃買中心公布的處置股，期間改為分盤交易、部分需預收款券，買賣比較不容易成交。
  • 卡片上的線：近30個交易日收盤走勢，紅色代表期間上漲。
  • 活躍度：在同市場內的綜合排名，1.00是最活躍。
  • 量能比：近5日均額除以近20日均額。
  • 波動：近20日日報酬標準差。
  • 漲停：近20日內單日漲9%以上的天數。

本頁是研究整理，不是買賣建議。
