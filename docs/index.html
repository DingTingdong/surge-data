強勢股雷達

目前結論

  • 這是「波動雷達」：找得到接下來會大幅波動的股票，但看不出方向（七年資料，預測大漲和大跌的能力一樣）。
  • 今日發動抓得最早：大漲波段中位數在第7天抓到，抓到時才漲約16%；但約3成之後會先跌10%。
  • 買了用移動停損賣：收盤比買進後最高收盤低10%就隔天開盤賣、最多抱20天。2024–2026平均每筆+0.89%，但中位數−4.47%，空頭年（2022）會賠。
  • 兩個待驗證的標示：「逆勢」（大盤偏弱時發動）和「融資未增」，2024–2026表現明顯較好，但都是看過結果才發現的，要等之後的實際資料確認。
  • 試過沒幫助的：只在大盤偏多時做、法人買超、續強／回落、舊版精選（量能比放大）、營收、產業集中（族群性）、股本大小。
  • 大跌時，扛跌和反彈快是兩種不同的股票：前段扛得住的，後面再跌也跌得少，但反彈也漲得少；跌最深的反彈最猛，再跌也跌最多。沒有找到大跌當下就能挑出「之後比較會漲」的條件。
  • 扣掉成本後還沒有證明能穩定賺錢，名單請當觀察用。實際表現看「追蹤」頁，第一批5日結果在11/24。

大跌時哪些股票扛跌、哪些反彈快

2020年以來，等權指數比近20日高點低6%以上的大跌共21次。三個發現：

1. 扛跌會延續，但反彈會落後。每次大跌，把前段跌最少的10%股票，和跌最多的10%比較，看之後20個交易日：

大盤下跌的日子大盤上漲的日子合計
前段最扛跌−10.8%+13.0%+2.1%
前段跌最多−16.6%+20.5%+4.0%

20次裡有19次「扛跌的之後再跌也跌得少」，20次全部「扛跌的反彈也漲得少」。所以扛跌和反彈快其實是同一件事的兩面：股票本身動得大或小。想要穩就挑扛跌的，想要彈就挑跌深的，很難兩個都要。（這一項是看過下面的結果後才做的，屬於探索。）

2. 跌最深的反彈最猛，但只在真正的低點才成立。如果知道哪天是低點，跌幅最大的那一成股票，之後10天平均比大家多漲3.7個百分點（20次有15次）。問題是低點只有事後才知道。

3. 大跌當下，沒有條件能挑出之後會漲比較多的股票。事先寫好7個條件（扛跌、大跌前強、法人買超、投信買超、大股本、高波動、仍在動），在跌破6%隔天買、看10天超額報酬，沒有一個在兩段期間都穩定有用。「仍在動」兩段都略好（約+1個百分點），但不夠穩。

這次（10月起）：10/28到11/06等權指數跌16.1%，11/06到11/13反彈8.5%，11/13到11/17又跌7.9%。兩段下跌的表現高度一致（相關係數0.73），扛跌的大多是食品、建材營造、航運、金融、電信和部分資訊服務股（如大世科、全景軟體、華經）；半導體、電子零組件、光電跌最深，反彈最大，第二段又跌最多。

大跌期間，雷達頁大盤卡片會出現「看最抗跌」「看跌最多」，可以直接看從高點以來每檔的漲跌。

舊版精選的門檻怎麼定的

四個條件全部符合才入選：

  • 活躍度前10%：波動、振幅、平均真實波幅、漲停天數、近期最大5日漲幅的綜合排名（上市、上櫃分開排）。
  • 今天或前10個交易日內有漲停（單日漲9%以上，近似值），排除早就熄火的。
  • 當天上漲：收盤高於前一天收盤（不是紅K棒）。
  • 量能比至少2：近5日平均成交額是近20日的2倍以上，代表資金正在湧入。

風險：舊版精選股在大盤下跌時一樣會跌，而且賠10%以上的比例明顯比全體高（驗證期30%對18%）。驗證期只有約5週，請看「追蹤」頁累積的實際結果。

要看清楚的地方

  • 這個規則找出的是大漲機率高約2.5到3倍的股票，但它們跌起來也更兇。10月到11/2大盤走弱，入選股的平均報酬比全體更差，單週跌20%以上的比例是漲20%以上的三倍。
  • 方向主要看大盤。11/2當週個股報酬中位數約−12%，11/9當週約+6.5%。入選股只是把大盤的漲跌放大。
  • 「量能增溫」（近5日均額不低於近20日）標籤，在三個期間都比單看活躍度略好，但差距小，樣本也少，只當參考。
  • 只有15週、一段行情。我沒有找到其他穩定有效的特徵。我先前憑感覺設的「突破20日高點、放量2倍」，資料不支持：大漲股反而多半離高點較遠。

持有追蹤（近20個交易日的今日發動）

假設每檔都在訊號隔天開盤買進，照移動停損規則：收盤比買進後最高收盤低10%就隔天開盤賣，最多抱20個交易日。價格已依除權息調整。

名單之後表現如何

每天收盤後，「今日發動」和「仍在動」的完整名單都會存檔，之後不再修改；規則改版就另開新紀錄（v1 的紀錄保留在 data/archive/）。報酬算法：隔天開盤買、第5個交易日收盤賣，扣約1.1%成本。開盤一價漲停視為買不到、不計入；出場日跌停鎖死順延；持有中停牌用最後收盤。

比較三組：今日發動、仍在動（不含今日發動）、全體，都用「抱5天」算。今日發動另外用移動停損算：收盤比買進後的最高收盤低10%就隔天開盤賣，最多抱20天。

「實際」是 起的名單，才算真正的驗證；「回測」是規則制定期間的名單，只供參考。

事先定好的停止條件

在看到實際結果之前先寫下，避免邊看邊改：累積約26週（130個交易日）實際結果後，如果今日發動的5日報酬中位數不高於「仍在動的其他股票」，或今日發動賠10%以上的比例超過35%，就停用今日發動分級，只保留「仍在動」當觀察名單。在那之前不調整門檻。

資料與更新

行情來自證交所與櫃買中心每日收盤資料，雲端排程每個平日台北18:30自動抓取並重新計算。清單包含近20日平均成交額1,000萬元以上、已有60日行情的上市櫃普通股。

各欄位

  • 今日發動（v2）：今天漲9%以上、前10個交易日都沒有漲9%以上（第一根漲停），今天成交額至少2,000萬、前20日平均至少300萬。代表剛發動，不代表比較值得買。
  • 仍在動：活躍度前10%（上市、上櫃分開排名），且今天或前10個交易日內有漲停。只代表最近震盪大，不分漲跌；再依收盤在5日均線上或下標成「續強」或「回落」。2020–2026回測中兩者之後的表現差不多（5日報酬中位數：續強約−2.5%、回落約−1.7%），所以只當標示，不代表續強比較好。
  • 今日量比：今天成交額 ÷ 前20個交易日平均成交額。
  • 起漲：今天收盤比近20個交易日最低收盤高多少（已做除權息調整），數字越小代表越早期。
  • 處置：證交所或櫃買中心公布的處置股，期間改為分盤交易、部分需預收款券，買賣比較不容易成交。
  • 卡片上的線：近30個交易日收盤走勢，紅色代表期間上漲。
  • 活躍度：在同市場內的綜合排名，1.00是最活躍。
  • 量能比：近5日均額除以近20日均額。
  • 波動：近20日日報酬標準差。

本頁是研究整理，不是買賣建議。
